## How to ask

Pass an article title or topic for page views. The trending-article list needs no keyword.

**Good to know:** This is page views and today's most-read articles. It does not return the article text.

## FAQ

**Do I need the exact article title?**  
Pass the article title or the topic. Page views are for that Wikipedia article.

**Does this include the article text?**  
No. It returns how often the article is viewed, and which articles are trending.

**Is the Wikipedia connector free?**  
Yes. The free plan has 100 requests a month and includes every source. No credit card. Paid plans start at $19 a month for 1,000 requests.

**Which AI apps work with it?**  
Claude, ChatGPT, Cursor, VS Code, Claude Code, Grok, Muse, Perplexity, Gemini, Copilot, Windsurf and any app that supports MCP connectors.
